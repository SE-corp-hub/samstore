# 10 · Order ng agent

**Agent (sariling phone):**
1. **Bagong order (agent)** → customer · bigas at ilan · address · saang tindahan.
2. **Ipadala.** Status: **Naghihintay**.
3. **Mga order ko** — makikita kung aprubado o tinanggihan (may dahilan).

**Staff ng tindahan:**
4. **Order ng agent** → buksan → **Aprubahan** (pipili ng pagkukunan; nakareserba ang bigas) o **Tanggihan** (may dahilan).
5. Mula rito, pareho na ng "Kunin sa ibang tindahan" (03): **Ilabas** → **Naihatid** → bayad.

**Bayad:** pagkatapos maihatid, para sa naihatid lang. Cash o utang. Utang ay kung may limit ang customer at **hindi lalampas** — kung lalampas, tatanggihan; ang may-ari ang magtataas ng limit muna.
