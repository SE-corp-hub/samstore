# 11 · Para sa iyo (may-ari / manager)

Lahat ng naghihintay ng desisyon mo ay nasa **Para sa iyo**:

- Utang na lalampas sa limit
- Lipat mula sa ibang tindahan (hindi WH)
- Resack, lipat o bawas na lampas 1% ang kulang
- Bilang (buong bilang) bago mag-adjust ang stock
- Ibinalik / refund
- Bagong item (Susuriin)

**Paano:** buksan → basahin ang buod at mga pirma → **Aprubahan** o **Tanggihan** (may dahilan) → ilagay ang PIN mo.
Isang beses lang napagpapasyahan ang bawat isa; nakatala kung sino at kailan.

**Araw-araw:** tingnan tuwing umaga at bago magsara. Ang hindi napagpasyahan ay nananatiling nakabinbin — hindi kusang naaaprubahan.
