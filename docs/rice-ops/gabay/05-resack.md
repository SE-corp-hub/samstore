# 05 · Resack at Buksan ang sako

**Resack** = anumang paglipat ng sako: 25 kg → 5 × 5 kg; 25 kg → ibang klase; sako → tingi.

1. **Resack** → **Ano ang papasok?** Piliin ang bigas at ilan. Piliin ang kargador kung siya ang gagawa.
2. **Ano ang lalabas?** Isa o higit pang produkto at ilan, at ang tingi (kilo mula sa timbangan).
3. Ipapakita ng app: kilo pumasok, kilo lumabas, at ang kulang.
   Hal.: 25.000 kg pasok, 24.800 kg labas, kulang 0.2 kg (0.8%) → **OK, pasok sa 1%**.
4. Pipirma ka at ang kargador. Gagalaw ang stock.

**Lampas 1% ang kulang?** Gagalaw pa rin ang stock, pero maghihintay ang kulang sa pag-apruba ng may-ari.
**Ibang klase** (hal. Sinandomeng → Dinorado): nakamarka sa ulat; dala ng bagong sako ang puhunan ng lumang bigas.
**Matagal?** Pindutin **Simulan** ngayon, **Tapusin** mamaya. Sa pagitan, "nasa resack" ang bigas — hindi nawawala.

**Buksan ang sako (tingi sa counter):** **Resack** → **Buksan ang sako (tingi)** → 1 sako papunta sa tingi (kilo). Pumirma.
