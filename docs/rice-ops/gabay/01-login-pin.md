# 01 · Mag-login gamit ang PIN

**Para kanino:** lahat ng staff, sa sariling phone.

1. Buksan ang Tindahan app (naka-install sa home screen).
2. Pindutin **Staff: mag-login gamit ang PIN**.
3. Ilagay ang **mobile number** mo at ang **4 na numerong PIN**.
4. Pindutin **Login**.

**Unang beses?** Ang may-ari ang nagbibigay ng pansamantalang password. Mag-login gamit iyon, at papipiliin ka ng bagong password. Pagkatapos, ang PIN na ang gamit araw-araw.

**5 beses mali ang PIN** → naka-lock ang PIN login nang 15 minuto. Maghintay, o magpa-unlock sa may-ari (Team → tao → Unlock).
**5 beses mali ang password** → naka-lock din nang 15 minuto. Ang may-ari ang makaka-reset ng password mo.

**Huwag:** ibigay ang PIN sa iba, o mag-login para sa kasama. Ang pangalan mo ang nasa bawat pirma.
**Bagong phone o nawala ang phone?** Sabihin agad sa may-ari — palitan ang PIN mo; masa-sign out ang lahat ng lumang phone.
