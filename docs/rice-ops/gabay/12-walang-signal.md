# 12 · Mahina o walang signal

**Mahina ang signal:** tuloy lang. Ang pinindot mo ay naka-save sa phone at ipapadala pagbalik ng signal. Makikita sa itaas: **Naghihintay ipadala (2)**.
- **Ipadala ngayon** — subukang ipadala agad.
- **Hindi naipadala** (pula) — tinanggihan ng system pagdating (hal. naubos na ang stock). Basahin ang dahilan at gawin ulit kung kailangan.
- Huwag i-uninstall ang app o burahin ang data ng browser habang may naghihintay.

**Walang signal / walang phone:**
1. Gamitin ang **numbered na papel na slip**. Isulat: oras, item, ilan, bayad, pirma.
2. Pagbalik ng signal: **Benta → Galing sa papel** — slip no., totoong oras, litrato ng slip.
3. Nakamarka itong "encoded later" sa ulat. Isang beses lang pwedeng i-encode ang bawat slip.

**Install sa home screen:** buksan ang app sa Chrome → menu (⋮) → **Add to Home screen**.
