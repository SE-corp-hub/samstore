# 12 · Agent orders

**Who:** the sales agent places orders (**New order (agent)**). Owner, manager and counter staff handle them in **Agent orders** (phone: **More** → **Other screens**). Staff see only their own store's orders.
**When:** a sales agent orders rice for a customer, to be delivered.

## Sales agent
1. Tap **New order**. Pick the **Store that delivers**.
2. Tap each rice. Type how many, or tap **Kilos** or **Pesos** for loose rice. Tap **Add**.
3. Type **Customer name**, **Customer mobile** and **Address**. **Landmark** and **Note** are optional.
4. Tap **Send the order**. It shows **Waiting**. No rice moves yet.
5. **My orders** shows each order's status. **Status** shows only the ones still moving. You cannot approve or change a price.

## Store staff
1. Open the **Waiting** tab. Check the rice and the address.
2. Under each rice, check the **Take from** box. It starts with the store the agent chose. Pick another store if it has the rice.
3. Tap **Approve**. The rice leaves that store's count **at once**. Or tap **Decline** and type the reason. The agent sees it. Declining changes no stock.
4. When the rice reaches the customer: **In progress** tab → **Delivered**. The count does not change.
5. Did not arrive? Tap **Not delivered** and type the reason. The rice goes back on the shelf it left. The order closes.
6. After **Delivered**, tap **Take payment**. Choose **Cash**, **GCash** (type the reference number) or **Credit** (the customer signs). Tap **Receive payment**. The order moves to **Done** as **Paid**.

## Good to know
- **Credit** needs a credit limit. A brand-new customer typed in by the agent has none. Use cash or GCash, or ask the owner (guide 03). At the limit, credit is refused.
- **Approve** can be refused if the store has too little. The screen says how much is left.

## Made a mistake?
- Approved by mistake: tap **Not delivered**. The rice goes back and the order is cancelled. The agent sends a new order.
- **Delivered** or a payment wrong: there is no Undo here. Tell the owner or manager.
